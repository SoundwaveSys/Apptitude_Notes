# Module 25 : Simplification and Approximation

Simplification is the process of finding the exact value of a mathematical expression. Approximation is finding a value that is "close enough" to the exact answer, which is crucial for quick mental math. Both rely heavily on the order of operations and basic arithmetic rules.

---

# The Golden Rule: BODMAS / PEMDAS

The order in which you perform operations changes the result. Always follow this hierarchy:

- **B / P:** Brackets / Parentheses `( ) { } [ ]` - Solve innermost first.
- **O / E:** Orders / Exponents `x² √x` - Powers and Roots.
- **D / M:** Division and Multiplication (Left to Right).
- **A / S:** Addition and Subtraction (Left to Right).

## Example

```text
12 - 4 ÷ 2
```

### Wrong Way

```text
(12 - 4) ÷ 2 = 4
```

### Right Way

```text
12 - (4 ÷ 2) = 12 - 2 = 10
```

# Fractions and Decimals

## Fraction Rules

### Addition / Subtraction

Find a Common Denominator.

```text
1/2 + 1/3 = (3 + 2) / 6 = 5/6
```

### Multiplication

Multiply Numerators together and Denominators together.

```text
2/3 × 4/5 = 8/15
```

### Division

Multiply by the Reciprocal.

```text
2/3 ÷ 4/5 = 2/3 × 5/4 = 10/12 = 5/6
```

# Surds and Indices (Powers and Roots)

## Laws of Indices

```text
a^m × a^n = a^(m+n)

a^m ÷ a^n = a^(m-n)

(a^m)^n = a^(mn)

a^(-n) = 1 / a^n

a^0 = 1
```

---

# Rationalizing the Denominator

We dislike square roots in the bottom of a fraction. To remove √a from the denominator, multiply top and bottom by the Conjugate.

### If denominator is √x

```text
Multiply by:

√x / √x
```

### If denominator is a + √b

```text
Multiply by:

(a - √b) / (a - √b)
```

# Algebraic Identities for Simplification

Memorizing these saves huge amounts of time.

```text
(a + b)^2 = a^2 + 2ab + b^2

(a - b)^2 = a^2 - 2ab + b^2

a^2 - b^2 = (a + b)(a - b)

(a + b)^3 = a^3 + b^3 + 3ab(a + b)

a^3 - b^3 = (a - b)(a^2 + ab + b^2)

a^3 + b^3 = (a + b)(a^2 - ab + b^2)
```

# Approximation Techniques

## Rounding Off

In Approximation questions (often labeled "What approximate value should come in place of (?)"), do not calculate exact decimals.

```text
49.99 → 50

12.01 → 12

3.94 × 15.02 → 4 × 15 = 60
```

---

# Percentage Shortcuts

```text
10%: Move decimal point one place left
10% of 450 = 45

5%: Half of 10%

1%: Move decimal point two places left
```
